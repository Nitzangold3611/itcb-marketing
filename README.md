# ITCB · תוכנית שיווק ושימור שותפים

אתר לניהול תוכנית השיווק השנתית של ITCB (עמותת הבודקים).
כתובת: https://itcb-marketing.netlify.app

## מבנה
- `public/`: האתר עצמו (`index.html`, `app.js`, `styles.css`, לוגו).
- `netlify/functions/api.mts`: השרת. כניסה, משתמשים, ונתוני התוכנית ב-Netlify Blobs.
- `netlify/functions/lib/seed.mjs`: הנתונים ההתחלתיים מהגיליונות. נטענים רק בפעם הראשונה, כשאין עדיין נתונים בשרת.
- `scripts/convert.py`: המרת קובצי ה-Excel המקוריים ל-seed.

## פריסה
כל דחיפה לענף `main` מפעילה פריסה אוטומטית ב-Netlify.

משתני סביבה שמוגדרים ב-Netlify (לא נשמרים בקוד):
`SESSION_SECRET`, `ADMIN_PASSWORD`, `ADMIN_EMAIL`, `ADMIN_NAME`.
