# ITCB · תוכנית שיווק ושימור שותפים

אתר לניהול תוכנית השיווק השנתית של ITCB (עמותת הבודקים).
כתובת: https://itcb-marketing.netlify.app

## מבנה
- `public/`: האתר עצמו (`index.html`, `app.js`, `styles.css`, לוגו).
- `netlify/functions/api.mts`: השרת. כניסה, משתמשים, ונתוני התוכנית ב-Netlify Blobs.
- `netlify/functions/lib/seed.mjs`: הנתונים ההתחלתיים מהגיליונות. נטענים רק בפעם הראשונה, כשאין עדיין נתונים בשרת.
- `scripts/convert.py`: המרת קובצי ה-Excel המקוריים ל-seed.

## פריסה
כל דחיפה לענף `main` מפעילה פריסה אוטומטית ב-Netlify.

משתני סביבה שמוגדרים ב-Netlify (לא נשמרים בקוד):
`SESSION_SECRET`, `ADMIN_PASSWORD`, `ADMIN_EMAIL`, `ADMIN_NAME`.

## בדיקות
לפני כל העלאה מריצים את כל הבדיקות:
```
npm install
npm test
```
- `tests/api.test.mjs`: בדיקות שרת (כניסה, טוקנים, הרשאות, משתמשים, משימות, סעיפים, שנים, נתוני seed).
- `tests/e2e/`: בדיקות דפדפן (Playwright + pytest): כניסה, סינון ומיון, הוספה/עריכה/העברה/מחיקה, XSS, דשבורד, מצב הצגה, גאנט, הזמנות, כניסה ראשונה, הרשאות בממשק, מובייל. כל שגיאת JavaScript בדף מכשילה את הבדיקה.
- הבדיקות רצות על שרת מקומי עם אחסון בזיכרון. הן לא נוגעות באתר החי או בנתונים האמיתיים.
- דוח: `tests/reports/latest.html` (מלא, עם צילומי מסך, לא נשמר בגיט) ו-`tests/reports/v<גרסה>.md` (נשמר בגיט עם כל גרסה).

דרישות מקומיות: Node 20+, Python 3 עם `pytest` ו-`playwright` (`pip install pytest playwright && playwright install chromium`).
